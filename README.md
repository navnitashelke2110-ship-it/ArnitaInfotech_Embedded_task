# ArnitaInfotech_Embedded_task
Measurement of Adulteration Content in Food A sensor-based embedded system that detects food adulteration in real time, classifies samples as pure or adulterated, and estimates adulteration levels with high accuracy.
This project focuses on the detection and measurement of food adulteration using electronic sensors and embedded systems. It is designed to identify whether a food sample is pure or adulterated and estimate the level of adulteration with high accuracy.
The system uses a combination of chemical, gas, and optical sensors to analyze food samples in real time. Sensor data is processed using a microcontroller, and the results are displayed on an LCD/OLED screen or transmitted to a mobile/web application in IoT-based implementations. Alerts are generated when adulteration exceeds safe limits.
Key Features
Real-time detection of food adulteration
Adulteration percentage / concentration measurement
Pure vs Adulterated classification
Fast response time (5–15 seconds)
High accuracy (≥ 90–95%)
Visual display and alert system
Data logging for analysis and reporting
Applications
Food quality monitoring
Consumer safety
Small-scale food industries
Research and educational purposes
Technologies Used
Embedded systems
Sensors (MQ sensors, pH, conductivity, optical sensors)
Microcontroller (Arduino/ESP/STM32 – as applicable)
LCD/OLED display
IoT (optional)
